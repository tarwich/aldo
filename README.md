# Physics Playground

A simple HTML5 physics simulation that's perfect for learning and experimenting with code. This single-file application demonstrates basic physics concepts like gravity, bounce, and friction in an interactive way.

## How to Use

1. Open `simple-game.html` in your browser
2. Click anywhere on the canvas to launch the ball in that direction
3. Watch the ball bounce around following physics rules
4. Experiment by modifying the `PHYSICS` parameters in the code:
   - `gravity`: Change the strength of gravity
   - `bounceEnergy`: Adjust how bouncy the ball is (0-1)
   - `friction`: Modify air resistance
   - `ballSize`: Change the size of the ball
   - `ballColor`: Try different colors

## Fun Experiments

- Set `gravity` to 0 for zero-gravity environment
- Make it super bouncy with `bounceEnergy` near 1
- Create low friction by setting `friction` close to 1
- Try negative gravity for an anti-gravity effect!
